race-schedule レポートダッシュボード

race-schedule / race-scheduler 両リポジトリのテスト・カバレッジ・品質レポートへの入口をまとめたページです。 各リポジトリは main への push・PR・定期実行のタイミングでこれらのレポートを自動更新します。

race-scheduler（front / api / batch / admin / db / core）

race-scheduler-ci-report main push・月次・手動実行で更新
  • テスト結果・カバレッジ・仕様網羅率
    UT / コンポーネント / sIT / UAT / front の実行結果一覧     ↗
  • Allure Report
    実行履歴・トレンドグラフ・タイムライン     ↗
  • Widgetbook
    Flutter デザインカタログ（atoms / molecules / organisms）     ↗
  • テスト失敗Issue
    main pushでのテスト失敗が自動起票される     ↗

その他

PRごとの行単位カバレッジHTML（race-scheduler-coverage / race-schedule-coverage）と Widgetbookのプレビュー（PRブランチ毎）はPR単位で内容が変わる一時的なプレビューのため、 ここには載せていません。各PRのコメント（coverage-html-report / widgetbook-preview）から確認してください。
